# World preview (โลกของร้าน)

หน้าเว็บสำหรับดู "เมืองจิ๋ว" 3D ของร้านบนเครื่อง ก่อนจะนำเข้าแอปมือถือ
ดึงข้อมูลจริง (โต๊ะ + ออเดอร์) จาก API เดียวกับแอป แบบ **อ่านอย่างเดียว**

## วิธีรัน

1. เปิด API (ที่พอร์ต 4000) เช่น `npm run dev:api` จากโฟลเดอร์รากของโปรเจกต์
2. ติดตั้งครั้งแรก แล้วเปิดหน้าเว็บ:

   ```bash
   cd apps/world-preview
   npm install
   npm run dev
   ```

3. เปิด http://localhost:5180 แล้วเข้าสู่ระบบด้วยบัญชี OWNER/ADMIN
   (หรือกด "ลองโหมด DEMO" เพื่อดูข้อมูลปลอม ซึ่งมีป้าย DEMO กำกับเสมอ)

## ข้อมูลมาจากไหน

- `GET /api/tables` และ `GET /api/orders?status=PENDING,PREPARING,READY`
- อัปเดตทันทีผ่าน socket.io (`table:updated`, `order:status`, `kds:new`) และดึงซ้ำทุก 8 วินาที
- Vite proxy ส่งคำขอ `/api` และ `/socket.io` ไปที่ `localhost:4000` และตัดหัวข้อ `Origin` ออก
  เพื่อไม่ต้องแก้รายการ CORS ของ API
- โทเค็นเข้าสู่ระบบเก็บใน `sessionStorage` ของแท็บนั้นเท่านั้น

## ธีม

- **ห้องแอร์ (ค่าเริ่มต้น)** ร้านอาหารในอาคาร มุมมองแบบบ้านตุ๊กตาเปิดด้านหน้า: ผนังครีมพร้อมหน้าต่างและผ้าม่าน พื้นไม้ (ครัวปูกระเบื้อง) แอร์ติดผนัง 4 ตัวพร้อมลมเย็นลอยลง ครัวเปิดมีเตา ฮูด ตู้เย็น และเคาน์เตอร์รับจาน (มีช่องให้พนักงานเดินผ่าน) บาร์พร้อมสตูล เครื่องชงกาแฟ ตู้เค้ก ระฆัง กระดานเมนู ป้ายนีออน โคมแขวน กระถางต้นไม้คั่น ประตูกระจกพร้อมป้าย OPEN โต๊ะต้อนรับ มุมรอนั่ง และมุมถ่ายรูป
- **เมืองกลางแจ้ง** ธีมเดิม (ขยายตามจำนวนโต๊ะ ดูหัวข้อถัดไป)
- สลับได้จากแถบด้านล่าง ผังโต๊ะ ท่าทาง และพฤติกรรมของทั้งสองธีมใช้ชุดเดียวกัน
- ระยะห่างโต๊ะ (`SX`, `SZ` ใน `src/world/layout.ts`) ปรับให้ห่างพอที่ลูกค้าโต๊ะข้างๆ ไม่นั่งชิดกัน

## ขนาดเมือง (ธีมเมืองกลางแจ้ง)

เมืองขยายตามจำนวนโต๊ะจริง (ปรับที่ `tierFor` ใน `src/world/layout.ts`):

| ขนาด | โต๊ะ | มีอะไรเพิ่ม |
|---|---|---|
| S | ไม่เกิน 8 | ลานโต๊ะ + ครัว เคาน์เตอร์ ออฟฟิศ + มุมถ่ายรูป/มุมพักผ่อน |
| M | 9–24 | + ถนนตลาด (แผงพร้อมอาหารยักษ์บนหลังคา) + สวนมีสระ/ศาลา/น้ำพุ |
| L | 25–48 | + สวนสาธารณะด้านหน้า (น้ำพุ ชิงช้าสวรรค์) + หอคอยแลนด์มาร์ก |
| XL | 49+ | + ถนนตลาดและสวนเพิ่มอีกชั้น + หอคอย 3 หลัง |

ตึกครัว/เคาน์เตอร์/ออฟฟิศใหญ่ขึ้นตามขนาด แสดงโต๊ะสูงสุด 80 ตัว (ที่เกินจะขึ้นเป็น "+N")
ในหน้าเว็บมีปุ่มบังคับขนาด และในโหมด DEMO เลือกจำนวนโต๊ะ 6/20/40/70 เพื่อดูการขยายได้

## ตัวละคร (Step 2)

- พนักงานจริงจาก `GET /api/employees` (เฉพาะที่ isActive) — ใช้ได้เมื่อล็อกอินเป็น OWNER/ADMIN
- ตัวกลมแนวดินน้ำมัน (clay): หัวกลมใหญ่ ตัวก้อนถั่ว แขนขาสั้น หน้าเรียบง่าย (ตาเม็ดมันวาว แก้มแดง ยิ้มเล็ก) ผม 8 แบบ (กระจุก/มวย/จุกคู่/ทรงชาม/มวยคู่/ผมยาว/ผมหยิก/หางข้าง) สุ่มคงที่จากชื่อ/รหัสพนักงาน ทั้งสีผม สีผิว โบว์ รองเท้า **ความสูง (0.9–1.12) และความอวบ**
- ชุดแต่ละบทบาทมี 5 โทนสี (รวมสีพิเศษ) และลายเสื้อ 4 แบบ (เรียบ/ลายขวาง/จุด/ดาว)
- เสื้อผ้า+อุปกรณ์ประจำบทบาท: KITCHEN เสื้อเชฟ+หมวกเชฟ · CASHIER ผ้ากันเปื้อนส้ม+กระโปรง · ADMIN เสื้อฟ้า+โบว์ไท+สมุด · OWNER เสื้อเหลือง+สร้อยไข่มุก+มงกุฎ
- ยืนประจำสถานี (ครัว / หน้าเคาน์เตอร์ / ออฟฟิศ) ส่วนที่เกินไปที่มุมพักผ่อน แสดงสูงสุด 24 คน
- ท่าทางตอนนี้เป็น idle: เด้งเบาๆ แบบยืด-หด มองรอบๆ กะพริบตา แขนแกว่ง ติ่งผมแกว่ง
- วงแหวนใต้เท้ายังเป็นสีเทา (สี เขียว/เหลือง/แดง รอ Step 3 ที่ผูกกับออเดอร์)
- ปุ่ม "ชื่อ" เปิด/ปิดป้ายชื่อ และปุ่ม "ไปที่" พากล้องบินไปดูสถานี

## พฤติกรรม (Step 3)

ผูกกับสถานะออเดอร์จริง (ดึงออเดอร์ล่าสุด 40 รายการ + ที่ยังไม่เสร็จทั้งหมด) และเทียบกับครั้งก่อนเพื่อจับเหตุการณ์

| สถานะ/เหตุการณ์ | สิ่งที่เห็น |
|---|---|
| ออเดอร์ใหม่ | ฟีดเหตุการณ์ + แคชเชียร์พิมพ์ใบสั่ง 🧾 |
| PENDING | พ่อครัวที่ว่างรอ ⏳ วงแหวนเหลือง |
| PREPARING | พ่อครัวคนหนึ่งต่อหนึ่งออเดอร์ทำอาหาร 🍳 วงแหวนเขียว ท่าคน |
| READY | จานโผล่ที่ช่องครัว มีประกาย พ่อครัวกระโดดดีใจ แคชเชียร์เดินไปรับจานแล้วถือเดินตามทางเดินไปวางที่โต๊ะ (ถ้าไม่มีโต๊ะ ส่งที่เคาน์เตอร์) |
| COMPLETED | เหรียญพุ่งที่ระฆัง แคชเชียร์ดีใจ 💰 จานหายไป |
| CANCELLED | ควันหายที่ช่องครัว 💨 |
| ช้า | ❗ เหนือโต๊ะ + วงแหวนแดงที่พ่อครัว (เกณฑ์ใน `src/world/sim/orders.ts` → `LATE_MS`) |
| ว่าง | คุยกัน 💬 · เจ้าของ/แอดมินเดินไปงีบที่มุมพักผ่อน 💤 หรือถ่ายรูป 📸 แล้วเดินกลับ |

### เสียง · ท่าทาง · ลูกค้า

- **เสียง** สังเคราะห์ในเบราว์เซอร์ (ไม่มีไฟล์เสียง) กระดิ่งออเดอร์ใหม่ เสียงทอด เสียงเรียกพร้อมเสิร์ฟ เสียงวางจาน เสียงเงิน เสียงเตือนช้า เสียงลูกค้าเข้า ปุ่ม 🔊/🔇 เปิด-ปิด (จำค่าไว้) เบราว์เซอร์จะเริ่มส่งเสียงหลังคลิกครั้งแรกเท่านั้น
- **ท่าทางเพิ่ม** ยืดเส้น โบกมือ ครุ่นคิด เต้น (เมื่อขายได้) · ลูกค้านั่ง กินข้าว โบกมือดีใจ
- **ลูกค้า** ตามสถานะโต๊ะจริง: โต๊ะเป็น OCCUPIED/BILLING → ลูกค้า 1–2 คนเดินเข้าจากประตูหน้านั่งที่เก้าอี้ · จานมาถึง → กิน 😋 · ออเดอร์ช้า → 😠 · โต๊ะว่าง → ลุกเดินออก
  (แสดงสูงสุด 36 คน; ลูกค้าเป็นตัวแบบเบากว่าพนักงาน)
- โหมด DEMO: ทุก ~14 วินาทีมีโต๊ะเต็มหนึ่งโต๊ะและโต๊ะที่เสร็จแล้วว่างหนึ่งโต๊ะ

หมายเหตุ: ตอนนี้ระบบไม่ได้บอกว่า "ใครทำออเดอร์ไหน" จึงใช้กติกาง่ายๆ: จำนวนพ่อครัวที่ทำงาน = จำนวนออเดอร์ที่กำลังทำ
โหมด DEMO มีตัวจำลองออเดอร์ที่เดินหน้าเองทุก ~9 วินาที (`src/world/sim/demo.ts`)
เปิด DevTools แล้วเรียก `__worldSim()` เพื่อดูสถานะตัวจำลอง (เฉพาะโหมดพัฒนา)

## โค้ดฉาก

`src/world/` เขียนด้วย React Three Fiber โดยตั้งใจให้ใช้ซ้ำกับแอปมือถือได้
(`@react-three/fiber/native` ถูกชี้มาที่เวอร์ชันเว็บใน `vite.config.ts`)

## Tap, extras and polish (Steps 4–6)

- Tap a person or a table → camera glides there → bottom sheet (read-only): orders, items, wait time. Tap empty space or ✕ to close; a tapped person is followed until you drag.
- Extras: flying order slips, auto day/night by the real clock (🕒 → ☀️ → 🌙), summary strip (late count, average wait), colourful dock with ⚙ scene settings.
- Polish: `Pacer.tsx` draws 30 fps when idle and ~60 fps while you interact, and lowers the resolution if the device is slow; soft vignette, fade-in, distance fog in the town theme.

## Cute pass
Expressive faces (happy ^^ eyes, frown, tasting mouth), bouncier walking with landing squash, the shop cat (tap it: meow), floating dust motes / fireflies / kitchen steam, festival themes (Christmas, Chinese New Year, Songkran, Loy Krathong) from the ⚙ panel, and a friendlier details sheet with an order progress path.
